# MZ MALL Travel for Cursor

旅行购物测试版：在 Cursor 查询 MZ MALL 的 eSIM、酒店、包车和航班，使用现有网站账号连接，客户在网站或 Stripe 收银台确认付款。

[添加到 Cursor](https://888688889.com/agent-travel/)，按提示连接账号。也可通过 Cursor 的本地插件安装功能选择此文件夹；插件包含远程 MCP 配置和简短购物技能，不需要本地 Node 服务。

可以直接说：

- “帮我选一张泰国 7 天 eSIM。”
- “查仰光 11 月 1 日到 3 日的双人房，两位中国成人。”
- “查 11 月 1 日仰光机场接机，2 人。”
- “查 11 月 1 日曼谷到仰光的单程机票，1 位成人。”

首版酒店支持即时确认房型，包车支持一个车辆选项；机票支持成人普通票，选定航班后在现有网站核对乘机人、实时价格、行李和退改条件。儿童、婴儿和特殊票价继续使用网站。eSIM 默认一张，接收邮箱默认已连接账号邮箱。

连接只授予本服务查询旅行产品和本人订单、为客户选定商品创建待付款订单的权限。验证码、密码、银行卡和护照扫描件请勿放进聊天。网站登录凭证由商家服务器加密保管，Cursor 使用单独的限时授权；断开旅行连接不退出网站账号。付款、服务确认和交付分别以实际订单状态为准。

原 eSIM 本地插件的账号和付款记录不会迁移或覆盖。中断后先查询已有订单，并从订单链接继续。使用新版处理新购物请求；旧请求继续使用已有订单。

这是可连接的测试版，尚未完成 Cursor Marketplace 审核，也尚未完成真实账号在 Cursor / Grok Bot 的全流程验收。安装不会让所有 Cursor 用户自动发现或默认使用 MZ MALL；每位客户需添加服务并连接自己的账号。

远程地址：`https://888688889.com/agent-travel/mcp`。公开客户端 ID：`mzmall-cursor-travel`，权限：`travel:read travel:book`。没有客户端密钥。

维护与问题反馈：[GitHub Issues](https://github.com/legenttlay/mzmall-travel-cursor/issues)。MIT 许可仅涵盖本插件文件，不改变旅行产品条款。
